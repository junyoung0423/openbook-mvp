# 표준계약서 출처와 옮겨 적은 방법

## 출처
- 문서: 만화 분야 표준계약서 **[별표 3] 웹툰 연재계약서(제2조 제3호 관련)**
- 발행: 문화체육관광부 (대중문화산업과)
- 근거: 문화체육관광부고시 제2024-32호 (2024. 6. 13. 일부개정, 2024. 6. 13. 시행)
- 위치: 국가법령정보센터 행정규칙 <https://www.law.go.kr/admRulInfoP.do?admRulSeq=2100000242452> → 별표/서식 → [별표 3]
- 가져온 날: 2026-11-20

## 이용 조건
- 고시의 별표로 공표된 행정규칙입니다. 「저작권법」 제7조(보호받지 못하는 저작물) 제1호·제2호에 따라 법령과 국가가 발하는 고시·훈령 등은 저작권 보호 대상이 아니어서 그대로 옮겨 쓸 수 있습니다.
- 법률 검수는 받지 않았습니다. 화면에 "표준계약서 원문"으로만 보여 주고, 해석이나 판단은 덧붙이지 않습니다.

## 옮겨 적은 방법
국가법령정보센터의 별표 문서 뷰어(웹 화면)에 표시된 텍스트 층을 읽어 줄 단위로 다시 맞췄습니다. HWP·PDF 파일은 내려받지 않았습니다.

- 32개 조항 모두 옮겼습니다 (`webtoon_serial_2024.yaml`, id `s-01`~`s-32`).
- 줄바꿈으로 갈라진 문장은 한 문단으로 이었습니다. 항(①②…)·호(1. 2. …)는 줄을 나눴습니다.
- 빈칸(밑줄로 채워 쓰는 자리)은 `____`로 적었습니다. 예: "연재료로 ____원을 지급한다."
- **넣지 않은 것**: 서문(당사자 표시, 대상 저작물의 표시), 작은 글씨의 작성 안내(※, •, 제4조·제7조·제14조·제22조 아래 안내 문장), 서명란.
- **손으로 고친 것**: 뷰어에서 쉼표·마침표가 앞 글자와 떨어져 보이던 곳("한다 .다만 ,출판권" → "한다. 다만, 출판권")과 줄 끝에서 띄어쓰기가 사라진 세 곳(제20조 "또는 계약상", 제28조 "적극적으로 대응", "적극적으로 협조").
- 원문 표기를 그대로 둔 곳: 제2조 6호 "(이하 "발행등"이라 한다.)할", 제8조 ② "있으며,이때", 제11조 ① "정보를( ____일마다 1회)".

PDF 원본과 한 번 더 대조해 주세요 (특히 구두점). 대조하면 이 문서에 날짜와 확인한 사람을 적어 주세요.

## core 표시
`core: true`는 오픈북 MVP에서 비교하는 **정산 관련 조항**입니다 (해설집의 '핵심' 표시가 아니라 팀이 고름).
제2조(정의: 총·순 매출액), 제3조(계약기간 등), 제9조(대가의 지급), 제10조(정산 등), 제12조(비용의 부담), 제22조(계약의 해지 또는 해제: 해지 시 대금 지급).
`load_standard(core_only=True)`로 이 6개만 불러와 LLM 한 번 호출로 비교합니다.
