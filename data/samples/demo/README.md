# 데모 자료 (가상 계약서·정산서)

**모두 데모용으로 만든 가상 자료입니다.** 회사·작가·작품 이름과 금액은 실제와 관계없습니다.
실제 계약서·정산서는 저장소에 넣지 말고 `data/private/`에 두세요.

| 데모 | 계약서 | 무엇을 보여 주나 |
|---|---|---|
| 1 | `demo1_contract.txt` / `.docx` | MG 회수형. 여러 달에 걸쳐 MG를 회수하고, 지급액이 적게 들어온 달과 계약서에 없는 공제가 낀 달이 있음 |
| 2 | `demo2_contract.txt` / `.docx` | MG를 회수하지 않는 계약(계약금 별도). 정률·정액 공제, 원 단위 처리 차이 1원 |
| 3 | `demo3_contract.txt` / `.docx` | 구간별 RS. 추측해서 계산하지 않고 '계산 불가'로 표시 |

## 돌리는 법

1. 서버 두 개를 켭니다 (`.claude/launch.json`의 `api`, `web`). 처음이면 먼저 DB를 만듭니다.
   ```
   backend/.venv/Scripts/alembic -c backend/alembic.ini upgrade head
   ```
2. http://localhost:3000 에서 회원가입합니다 (가짜 이메일, 예: `me@example.test`).
3. 계약서를 올립니다.
   - 파일: `demoN_contract.docx`를 고릅니다 (문서 읽기 API를 씁니다).
   - 본문: `demoN_contract.txt` 내용을 붙여넣습니다.
4. 조건 화면에서 필수 조건 5개를 확인하고 체크한 뒤 저장합니다.
5. 정산서 화면에서 `demoN_statements.txt`의 블록을 **한 달씩** 붙여넣고, "표에서 값 읽기"를 누른 뒤 "정산서 저장"을 누릅니다.
6. "대조 결과 보기"를 누릅니다.

조건 추출은 AI가 하므로 실행할 때마다 조금 다를 수 있습니다. 아래 값과 다르면 조건 화면에서 고친 뒤 확정하세요.

## 조건 화면에서 확인할 값

| 조건 | 데모 1 | 데모 2 | 데모 3 |
|---|---|---|---|
| MG 금액 | 3000000 | 1000000 | 2000000 |
| MG 회수 방식 | RS에서 차감 | 별도 처리 | RS에서 차감 |
| RS 배분율 | 0.65 | 0.5 | 구간별 (계산 안 함) |
| 정산 기준 매출 | 순매출 ※ | 총매출 | 순매출 |
| 공제 항목 | 앱마켓 수수료 비율 0.3 | 결제 수수료 비율 0.05, 서버 운영비 금액 50000 | 앱마켓 수수료 비율 0.3 |

※ 데모 1은 2026-11-23 실행에서 '정산 기준 매출'을 찾지 못했습니다. 그러면 직접 '순매출'을 고르고 체크하세요 (찾지 못한 조건을 직접 채우는 흐름).

## 기대 결과 (손으로 계산한 값, 계산 규칙 임시 안 기준)

계산식: 작가 몫 = (총매출 − 계약서 공제) × RS율 (원 미만 버림). MG 회수형이면 지급액 = max(0, 작가 몫 − 남은 MG).
차이 = 계약서 기준 금액 − 정산서 금액.

### 데모 1 (MG 3,000,000원, 65%, 앱마켓 수수료 30%)

| 월 | 작가 몫 | 남은 MG (전 → 후) | 계약서 기준 | 정산서 | 차이 | 확인 질문 |
|---|---|---|---|---|---|---|
| 3월 | 1,400,000 × 0.65 = 910,000 | 3,000,000 → 2,090,000 | 0 | 0 | 0 | 남은 MG |
| 4월 | 2,100,000 × 0.65 = 1,365,000 | 2,090,000 → 725,000 | 0 | 0 | 0 | 남은 MG |
| 5월 | 2,800,000 × 0.65 = 1,820,000 | 725,000 → 0 | 1,095,000 | 1,000,000 | **95,000** | 계산 내역, 남은 MG |
| 6월 | 2,450,000 × 0.65 = 1,592,500 | 0 → 0 | 1,592,500 | 1,527,500 | **65,000** | 계산 내역, '운영 대행 비용' 근거, 남은 MG |

6월 정산서는 계약서에 없는 '운영 대행 비용' 100,000원을 더 공제했습니다.

### 데모 2 (MG 별도, 50%, 결제 수수료 5% + 서버 운영비 50,000원)

| 월 | 공제 | 작가 몫 = 계약서 기준 | 정산서 | 차이 | 확인 질문 |
|---|---|---|---|---|---|---|
| 1월 | 60,000 + 50,000 | 1,090,000 × 0.5 = 545,000 | 545,000 | 0 | 없음 |
| 2월 | 49,382 + 50,000 | 888,272 × 0.5 = 444,136 | 444,135 | **1** | 계산 내역, 결제 수수료 금액(정산서 49,383 / 계약서 기준 49,382) |

2월은 결제 수수료 987,654 × 0.05 = 49,382.7원을 정산서는 올림, 오픈북은 버림으로 처리해서 1원 차이가 납니다.

### 데모 3 (구간별 RS)

| 월 | 결과 |
|---|---|
| 3월 | 계산 불가: "구간별 RS는 아직 계산하지 않습니다." 확인 질문(계산 내역, 남은 MG)은 나옵니다 |
