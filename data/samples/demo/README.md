# 데모 자료 (가상 계약서·정산서)

**모두 데모용으로 만든 가상 자료입니다.** 회사·작가·작품 이름과 금액은 실제와 관계없습니다.
실제 계약서·정산서는 저장소에 넣지 말고 `data/private/`에 두세요.

| 데모 | 계약서 | 무엇을 보여 주나 |
|---|---|---|
| 1 | `demo1_contract.txt` / `.docx` | MG 회수형(순매출). 여러 달에 걸쳐 MG를 회수하고, 작가지급액이 적게 들어온 달과 계약서에 없는 공제가 낀 달이 있음 |
| 2 | `demo2_contract.txt` / `.docx` | MG를 회수하지 않는 계약(계약금 별도). 정률·정액 공제, 원천징수 세율이 틀린 달 |
| 3 | `demo3_contract.txt` / `.docx` | 구간별 RS. 추측해서 계산하지 않고 '계산 불가'로 표시 |

## 돌리는 법

1. 서버 두 개를 켭니다 (`.claude/launch.json`의 `api`, `web`). 처음이면 먼저 DB를 만듭니다.
   ```
   backend/.venv/Scripts/alembic -c backend/alembic.ini upgrade head
   ```
2. http://localhost:3000 에서 회원가입합니다 (가짜 이메일, 예: `me@example.test`).
3. 계약서를 올립니다.
   - 파일: `demoN_contract.docx`를 고릅니다 (문서 읽기 API를 씁니다).
   - 본문: `demoN_contract.txt` 내용을 붙여넣습니다.
4. 조건 화면에서 필수 조건 5개를 확인하고 체크한 뒤 저장합니다.
5. 정산서 화면에서 `demoN_statements.txt`의 블록을 **한 달씩** 붙여넣고, "표에서 값 읽기"를 누른 뒤 "정산서 저장"을 누릅니다.
6. "대조 결과 보기"를 누릅니다.

조건 추출은 AI가 하므로 실행할 때마다 조금 다를 수 있습니다. 아래 값과 다르면 조건 화면에서 고친 뒤 확정하세요.

## 기대 결과 (손으로 계산한 값, 계산 규칙 R1–R12 기준)

규칙 문서: `docs/calc-rules/손계산_케이스_검산표.md` (허정민 님 손계산 C01–C20, 엔진 테스트 `backend/tests/test_calc_cases.py`).

- 정산 기준이 총매출이면 G = 매출액, D = 계약서 공제 합계. 순매출이면 G = 회사입금액, 공제 목록은 쓰지 않음 (R1·R2)
- 정산액(작가 몫) S = (G − D) × RS율. 화면에는 원 미만 버림 (R12)
- MG 회수형: 지급액 P = max(0, S − 남은 MG) 원 미만 버림, 남은 MG는 다음 달로 이어짐 (R3·R9). MG 별도: P = S (R4)
- 원천징수 = 소득세 3%(10원 미만 버림) + 지방소득세 = 소득세의 10%(10원 미만 버림) (R11)
- 작가지급액 = P − 원천징수 (R7)
- **차이 = 정산서 − 계약서 기준.** 음수면 정산서가 적게 준 것

### 데모 1 (MG 3,000,000원 회수형, 순매출 65%)

| 월 | 정산액 (계약서 / 정산서 / 차이) | 남은 MG (전 → 후) | 지급액 P | 원천징수 (계약서 / 정산서 / 차이) | 작가지급액 (계약서 / 정산서 / 차이) | 확인 질문 |
|---|---|---|---|---|---|---|
| 3월 | 1,400,000 × 0.65 = 910,000 / 910,000 / 0 | 3,000,000 → 2,090,000 | 0 | 0 / 0 / 0 | 0 / 0 / 0 | 남은 MG |
| 4월 | 2,100,000 × 0.65 = 1,365,000 / 1,365,000 / 0 | 2,090,000 → 725,000 | 0 | 0 / 0 / 0 | 0 / 0 / 0 | 남은 MG |
| 5월 | 2,800,000 × 0.65 = 1,820,000 / 1,820,000 / 0 | 725,000 → 0 | 1,095,000 | 32,850 + 3,280 = 36,130 / 36,130 / 0 | 1,058,870 / 963,870 / **−95,000** | 계산 내역, 남은 MG |
| 6월 | 2,450,000 × 0.65 = 1,592,500 / 1,527,500 / **−65,000** | 0 → 0 | 1,592,500 | 47,770 + 4,770 = 52,540 / 50,400 / **−2,140** | 1,539,960 / 1,477,100 / **−62,860** | 정산액, 원천징수, 계산 내역, '운영 대행 비용' 근거, 남은 MG |

- 5월: 정산액·원천징수는 맞는데 작가지급액이 95,000원 적습니다 (MG를 더 뗀 것으로 보임).
- 6월: 정산서가 계약서에 없는 '운영 대행 비용' 100,000원을 더 빼고 정산액을 계산했습니다. 그만큼 원천징수도 줄었습니다.
